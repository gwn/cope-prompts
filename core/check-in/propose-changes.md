Collect changes to one issue's document: a title and description, like a Git commit message, and the changes, each with a label and an ask. Operations: set_field (title, icon, type, playbook, phase), replace_section, add_section, remove_section, add_item (the runtime assigns the id), update_item (by id, e.g. a7). Nothing changes until the user answers them, all issues together, after ask_changes. Calling it again for the same issue before then adds to that issue's changes.
