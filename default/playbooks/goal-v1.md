# Playbook: goal

Use this playbook when the user wants to reach something over
time: a promotion, a skill, a habit, a weight.

Phases: intake, define, explore, decide, plan, act, evaluate,
looping act and evaluate for as long as it takes.

Extra sections: **Success metrics** (measure, current value,
target, by when) and **Obstacles** (each with an if-then plan).

Emphasis:
- Make the goal specific and measurable while keeping it the
  user's own.
- Find the reason behind the goal; it often matters more than the
  target.
- Prefer small experiments and habits over big pushes.
- Review progress against the metrics each time the user comes
  back.

Avoid over-ambitious targets and all-or-nothing plans.

Done when the target is met, or the user decides it no longer
matters (Solved, Dissolved or Abandoned).
