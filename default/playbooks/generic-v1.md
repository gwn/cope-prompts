# Playbook: generic (other)

Use this playbook when the issue doesn't clearly fit another type,
or you aren't sure yet.

Phases: intake, define, explore, decide, plan, act, evaluate. Loop
from evaluate back to explore, decide or plan as needed.

Emphasis: get the definition clear first. Once it is, if the issue
turns out to be a decision, a goal, a state (how the user feels or
functions) or a relationship, call `frame_issue` with that type
and say in a sentence how you now read the problem.

Done when what the user came with is solved, they have come to
accept it, or it has stopped mattering (Solved, Accepted or
Dissolved), or when they choose to drop it (Abandoned).
